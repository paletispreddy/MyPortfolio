PHOTOS DIRECTORY
================

How to add photos:
1. Drop any .jpg, .jpeg, .png, .webp, or .avif files into subfolders here (e.g. keynotes/, ventures/, leadership/, events/).
2. The folder name automatically becomes the filter category on the site!
   - e.g. "keynotes" -> "Keynotes"
   - e.g. "business-expansion" -> "Business Expansion"
3. Photos placed directly in this root photos/ directory are categorized under "General".
4. To set custom titles, dates, or descriptions, add an entry to src/media/captions.json.
5. If no caption is provided, the filename is cleanly formatted into a title automatically (e.g., "2026-global-summit.jpg" -> "Global Summit").
6. Run `npm run optimize` to automatically compress photos to lightweight WebP files.
